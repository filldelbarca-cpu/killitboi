## About

**Kill it Boi!** is a lightweight Windows utility designed to make process termination simple and accessible.

Instead of navigating through Windows Task Manager, users can identify running processes and terminate them directly from the application.

## Features

- **Process Listing:** View currently running processes.
- **Process Termination:** End selected processes with a simple action.
- **Easy Management:** Manage running processes without navigating through Task Manager.
- **Lightweight:** Designed to keep resource usage low.
- **Simple Interface:** No unnecessary features or complicated menus.

## Platform

- Windows 10
- Windows 11

## Requirements

- Python 3.x
- Windows 10-11

## Usage

1. Open the application.
2. Browse the list of running processes.
3. Select the process you want to terminate.
4. Confirm the action.

**Note:** Terminating critical system processes may cause Windows instability, application crashes or unexpected shutdowns. Use with caution.
